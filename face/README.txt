Своя картинка для окна Джарвиса

1. Положи сюда картинку и назови её idle.png (подойдут и .jpg, .webp).
   Лучше всего — персонаж по пояс, крупно, на однотонном или прозрачном фоне.
2. Для оживления добавь кадры с тем же размером и положением персонажа.
   Любой кадр можно пропустить — вместо него будет показан ближайший подходящий.

   Базовые:      blink, talk1, talk2, think, listen
   Взгляд:       look_left, look_right, look_up, look_down
   Эмоции:       happy, sad, angry, surprised, shy, wink, wave (машет рукой)
   Речь в эмоции: happy_talk1, happy_talk2, sad_talk1, sad_talk2 ... (для любой эмоции)

   Например, есть только idle, happy и talk1: радостная речь покажет talk1 и happy,
   обычная — talk1 и idle.
3. Перезапусти Джарвиса.

Если рисунок вышел «негативом» — поменяй FACE_INVERT в config.py.
Удали картинки из папки, чтобы вернуть встроенную Джарвис-тян.
